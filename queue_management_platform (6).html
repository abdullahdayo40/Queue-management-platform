Developer Docs

QueueOptimizer REST & WebSocket API

Integrate digital token generation, live queue position polling, and counter state management into your hospital, bank, or government kiosk software.

POST /api/v1/tokens Generate Token

Issues a new digital queue token for a specified service category ID.

curl -X POST https://api.queueoptimizer.io/v1/tokens \
  -H "Authorization: Bearer qop_live_sec" \
  -d '{"service_id": "General", "client_type": "web_kiosk"}'
GET /api/v1/queue/live Stream Queue

Establishes a real-time WebSocket connection for live queue positions and wait times.

const ws = new WebSocket('wss://stream.queueoptimizer.io/v1');
ws.onmessage = (event) => console.log(JSON.parse(event.data));
Compliance & Security

Privacy Policy & Data Governance

Last updated: January 2026

1. Data Minimization Principles

QueueOptimizer operates on a strict data minimization protocol. We do not require permanent user accounts, personal home addresses, or sensitive credentials to issue queue tokens. Digital token passes are anonymized and associated exclusively with temporary session IDs.

2. Ephemeral Data Retention

All active token queue data, counter assignments, and session timestamps are stored ephemerally in active memory or secure encrypted caches. Records are automatically purged within 24 hours of service completion to ensure absolute user privacy.

3. Encryption & Transmission Security

All data transferred between citizens, kiosks, staff dashboards, and central queue servers is encrypted in transit using industry-standard TLS 1.3 protocols. WebSocket feeds are token-authenticated to prevent unauthorized interception.
